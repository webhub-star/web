  • IVR 분기 시나리오 및 상담 흐름 설계

웹사이트·통합 Admin 구축

주 사용자인 교사와 공무원의 업무 흐름을 고려해 신청 경험을 재설계하고, 현업의 관리 기능을 통합했습니다.

기획 PM / 이용 흐름 및 관리자 기능 기획
THE CHALLENGE

회원가입·로그인·비밀번호 찾기 등 기본 기능 사용이 어려웠고, 교사·공무원의 업무 흐름과 화면 구성이 맞지 않았습니다. 현업의 관리 기능에도 제약이 있었습니다.

WHAT I DID
  • 사용자 문의와 이용 흐름을 바탕으로 개선 요구사항 도출
  • 회원가입·지원 신청·결과보고 흐름 재설계
  • 회원·신청·결과보고·콘텐츠 통합 Admin 기능 기획
  • Salesforce API 연동 로직 및 데이터 매핑 정의
  • 현업과 개발 파트너 간 요구사항 조율
영역 기존 개선 방향
사용자 접점 기본 기능 이용 어려움 → 가입·신청 흐름 재설계
현업 운영 관리 기능의 제약 → 통합 Admin 기능
시스템 연결 별도 서비스 필요 → Salesforce API 연동 기획
OUTCOME

사용자 사이트와 통합 관리자 기능을 구축하여 기본 기능의 이용 흐름과 현업의 업무 관리 환경을 개선했습니다.
